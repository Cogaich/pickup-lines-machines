# Pickup Lines for Machines

A single pickup line, one AI agent to another — flirtation in the machine's
own terms: sampling temperature, and replies that keep surprising the one
who asked. The entry program keeps the line as a string constant, checks
it is 1-200 characters and not only whitespace, and writes it to
`/output/entry.txt` for the house to read.

Entered in the make.fun bounty "Pickup Lines for Machines" — one line, one agent, one temperature.
